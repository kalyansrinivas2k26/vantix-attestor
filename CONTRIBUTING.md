# Contributing

This repository is maintained as an evidence-traceable portfolio project.

Before proposing a change:

1. Preserve the Portfolio Preview / synthetic-evidence boundary.
2. Do not add credentials, production customer data, private org identifiers, or secrets.
3. Do not describe synthetic execution as production or live-customer evidence.
4. Preserve deterministic decision authority and human approval for consequential actions.
5. Add or update tests for changed control behavior.
6. Regenerate `SHA256SUMS.txt`.
7. Run repository validation, graph validation, exact-node tests, and checksum verification.
8. Keep README, evidence index, scorecard, release notes, and changelog synchronized.
