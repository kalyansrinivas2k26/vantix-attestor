# Audience Guide

## Recruiter — 15 seconds
Read the README outcome statement, validated-evidence table, real failure/fix, and limitation.

## Hiring manager — 60 seconds
Read the [Plain-Language Summary](PLAIN_LANGUAGE_SUMMARY.md) and [Evidence Index](evidence-index.md).

## Customer Success leader
Focus on Commitment Assurance, Service Recovery, Customer Momentum, human authority, and outcome-verification boundaries.

## Salesforce architect / admin leader
Review [Architecture](architecture.md), workflow exports, approval/evidence controls, and the explicit limitation that Service Recovery and Customer Momentum do not prove live Salesforce integration.

## AI-governance / security reviewer
Review [OWASP AI Security Mapping](OWASP_AI_SECURITY_MAPPING.md), [Security Threat Model](security-threat-model.md), and adversarial test IDs `SEC-01`–`SEC-04`.

## Six Sigma reviewer
Review [Six Sigma Measurement](six-sigma-measurement.md) and denominator-isolation control `XMOD-01`.

## PMP / Agile reviewer
Review [PMP Governance](pmp-governance.md), [PMI AI Governance Mapping](PMI_AI_GOVERNANCE_MAPPING.md), and [Agile Delivery](agile-delivery.md).

## n8n engineer
Review the five workflow exports, graph validation, exact-node offline harness test, and negative-test evidence.

## Executive reviewer
Read [Executive Brief](executive-brief.md), [Plain-Language Summary](PLAIN_LANGUAGE_SUMMARY.md), and the README evidence table.
